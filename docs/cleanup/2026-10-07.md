## Not done

- **`features/sketch-bar.js` is one 852-line closure** (`_buildSketchBar`). It
  moved whole; splitting it means pulling its inner functions apart, which is a
  refactor of the toolbar, not a move.
- **`main.js · onload` is 395 lines** of registrations. Left as it is: it reads
  top to bottom as the list of what the plugin registers.
- **Still over ~300 lines:** `views/capturehub.js` (711), `modals/cards.js`,
  `lib/kanban.js` (470 each), `constants.js`, `lib/foldernotes.js`,
  `modals/bookcapture.js`, `lib/vaultsyncrun.js`, `views/galaxy.js`. Not part of
  this pass.
- **Exports used only inside their own file or only by tests** (~150 names).
  Removing them from `module.exports` is churn with no reader benefit; several
  are the surface the tests drive.
- **Debounce ×3** (`icons`, `foldernotes`, the dashboard): each is one line in
  the idiom the code already uses, with its own delay. Obsidian's `debounce`
  would change nothing a reader sees.
- **`sketchexport.deflate` vs `zip.deflateRaw`**: different formats (`deflate`
  vs `deflate-raw`), five lines each.
- **Single-level `vault.createFolder` ×11** (`if (!getAbstractFileByPath(dir))`).
  Merging them onto `ensureFolder` would switch them from the vault API to the
  adapter; not without a run in Obsidian.
- **`nx-card` / `nx-dot`** in `00-tokens.css` have no user yet. They are
  documented design primitives, and the token block is mirrored in the theme.
- **`pinnedTabs.tasks`, `focus`, `sprint`, `editorial`, `vaultSync.shared`** in an
  existing `data.json` are left alone and ignored — dead but harmless, as
  `docs/removed-features.md` says for the older ones.
